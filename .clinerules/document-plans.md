When planning a new task, record all planned actions in a markdown file saved in the /planning directory. Name the planning document `yyyy-mm-dd {Task Type}: {Description}`

Where Task Type is one of [Feature, Fix, Documentation, Testing, Miscellaneous]

And Description is a few-word description of the goal

At the top of the document, say "This plan was generated by {Model Name}". Use your full model name i.e. Gemini-2.5-pro rather than just Gemini
